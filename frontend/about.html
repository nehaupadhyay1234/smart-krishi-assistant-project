About Our Project

Smart Krishi Assistant is a smart farming solution designed especially for small and tribal farmers. The system helps farmers make better decisions about irrigation, pesticide usage and crop management.

🎯 Our Objective

Many farmers use pesticides and water without proper calculation, which increases cost and can harm crops. Our project uses land area, crop information and weather conditions to provide accurate farming recommendations.

🌱 Key Features

  • 🗺️ Field boundary mapping using digital maps
  • 📐 Land area calculation from perimeter points
  • 💧 Water requirement calculation
  • 🧪 Pesticide quantity recommendation
  • 🌦 Weather based irrigation advice
  • 📄 Farming report generation
  • 🌾 Crop based fertilizer suggestions

🚀 Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Node.js & Express.js
  • MongoDB
  • Leaflet Map API
  • Weather API

🌍 Vision

Our vision is to support tribal and rural farmers with technology so they can reduce farming cost, save resources and increase crop productivity.
